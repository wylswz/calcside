{{- if .Values.worker.enabled }}

Workers are addressed by stable StatefulSet pod name. Scaling the StatefulSet
down deletes the instances bound to the removed pod; their TTL will clean up
the database records. Scaling up changes the API worker list and rolls the API.

{{- if and (eq .Values.database.driver "sqlite") .Values.migrations.enabled }}

{{- if and .Values.worker.enabled (gt (int .Values.worker.instanceMemoryMax) 0) }}

WARNING: worker.instanceMemoryMax requires a writable cgroup v2 filesystem.
